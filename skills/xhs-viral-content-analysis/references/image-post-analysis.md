# 小红书图文解析方法

## 适用范围

仅用于包含标题、封面或首图、发布区正文和静态配图序列的小红书图文笔记。包含视频文件或主要叙事依赖动态画面的内容不纳入当前工作流。

一个分析批次必须明确为：

> 研究对象或产品 × 小红书 × 图文

先逐篇核读完整成品，再做跨样本比较。不得只抽取标题、正文或互动数字后直接归纳规律。

## 一、逐篇七项组成分析

每条纳入样本都按以下七项记录；缺失时写明缺失，不补造内容：

1. **标题**：点击前提出的用户任务、核心张力和阅读承诺；检查它与封面的承接，而不是统计固定句式。
2. **封面或首图**：对象识别、内容类型、第一层价值和视觉证据；判断它是在展示产品、声明攻略、建立比较，还是制造场景代入。
3. **开头钩子**：如何把处境、痛点、身份愿望、结果反差或选择冲突转成继续阅读的理由。
4. **正文**：发布区正文和承担正文功能的图片信息卡分别如何组织问题、产品、体验、解释与判断。
5. **图片序列与主要载体**：每张图的信息任务、前后推进、与正文的分工，以及整篇主要信息实际发生在哪里。
6. **决策收口**：最后是否给出适用条件、选择字段、使用取舍、坚持门槛、不适用边界或明确判断。
7. **证据与风险**：每项重要观察由什么支持，哪些只是个人体验、推断或待核验主张，是否存在评论反例、条件不一致或证据缺口。

标签、搜索词和互动字段可以作为补充事实记录，但不替代以上七项，也不自动解释表现原因。

## 二、主要信息载体判断

先判断主要信息载体，再解释标题、封面、正文和图片的分工：

- `post_body`：发布区正文承担主要解释。
- `image_cards`：配图信息卡承担主要论证，图片本身相当于正文。
- `scene_images`：真实场景、过程或结果部位图片承担主要叙事与信任表达。
- `mixed`：正文与配图共同承担主要逻辑，任一方缺失都会明显破坏理解。
- `unclear`：现有证据不足以判断。

主要载体是信息位置，不是质量评级。不得预设“正文解释、图片支持”，也不得因发布区正文较短就认定内容不完整。

## 三、正文六变量

无论主要载体位于发布区正文还是图片信息卡，都用六个变量描述其说服组织。变量是观察维度，不要求每篇按固定六段出现：

1. **开场**：以结果、身份、处境、旧认知、筛选结论或比较冲突中的哪一种进入。
2. **痛点组织**：如何把泛化需求变成具体场景、复合矛盾、选择困难或坚持阻力。
3. **产品进入**：产品在什么时点出现，以唯一主角、组合成员、首选项、比较选项或方法工具中的哪种角色进入。
4. **价值转译**：内容如何把产品特征、使用方式或信息细节转成用户能理解的收益、成本降低或决策价值。
5. **体验细节**：出现了哪些可感知的质地、气味、动作、流程、时间、部位、负担、限制或作者感受，以及证据能支持到哪里。
6. **最终判断**：最后形成的是继续使用、适用人群、组合方式、排名、比较取舍、购买参考还是未完成判断。

记录变量之间的实际顺序和缺口。不要把某一批样本出现的六步顺序写成通用公式。

## 四、模块与说服节点分层

模块是用户实际看到的成品组成，例如标题、封面、发布区正文和图片。说服节点是这些模块共同完成的信息关系，例如：

- 问题、处境或身份代入。
- 强承诺、悬念、结果反差或选择冲突。
- 产品或方案进入。
- 方法、过程、使用步骤或比较字段。
- 可感知体验、观察或结果叙述。
- 信任表达、反例、限制或证据校准。
- 适用条件、坚持判断、组合建议或选择取舍。

逐篇记录节点由哪个模块承担、前后如何承接、哪些节点缺失。跨样本只总结反复出现或具有路线区分价值的关系，不要求所有路线拥有相同节点数。

## 五、图片序列分析

按顺序为每张图记录：

- 稳定证据 ID 和图片位置。
- 它承担的单一或复合信息任务，例如对象识别、场景代入、问题定义、步骤、过程、质地、比较字段、结果部位、信息卡正文或决策总结。
- 它承接了标题、正文或前一张图的什么信息，又把什么交给下一张图。
- 画面可直接观察到什么。
- 该画面不能单独证明什么。

再判断序列是否完成信息推进，是否存在重复、跳步、证据不足或可合理合并的任务。图片数量不是通用质量规则。

## 六、价值转译

对反复出现或影响路线判断的卖点表达，使用以下链条：

> 用户阻力或任务 → 产品特征与内容细节 → 用户价值 → 产品角色与证据

“用户价值”必须是从样本内容中观察或合理解释出的决策价值，不得把作者表达直接升级为产品事实。至少区分：

- 可观察的包装、形态、动作、场景和页面信息。
- 需要条件化表达的个人体验。
- 需要企业资料支持的产品事实、用法和适用范围。
- 需要更高等级证据的健康、功效、机理、结果和竞品比较主张。

## 七、内容路线提纯

路线从样本差异中产生，不使用预设类别强行归类。每条路线统一输出五个核心字段：

1. **用户任务**：用户希望完成什么理解、判断或选择。
2. **核心张力**：推动阅读的处境冲突、结果期待、身份愿望或选择矛盾。
3. **主要信息载体**：主要论证位于发布区正文、图片信息卡、场景图还是混合载体。
4. **产品位置与角色**：产品是唯一主角、组合成员、首选项、比较选项还是辅助工具。
5. **使用前提**：这条路线成立所需的真实素材、比较口径、产品事实、使用主体和证据条件。

同时记录支持样本、模块承接、说服节点、不适用条件、反例、置信程度和限制。只有一个支持样本时标记为单样本路线，不升级为稳定规律。

## 八、跨样本结论

分开输出：

- 跨样本反复出现的共性。
- 由用户任务、产品角色、主要载体或证据条件造成的路线差异。
- 只在单篇出现、不能外推的结论。
- 与主结论冲突的反例和替代解释。
- 当前样本不能回答的问题。

指标只作为采集时点事实。缺少统一流量来源、投放条件、发布时间窗和对照时，不推断标题、封面、正文或图片导致了表现结果。

## 九、完成前检查

- 每条纳入样本是否核读完整标题、封面、发布区正文和图片顺序。
- 七项组成和正文六变量是否逐篇记录，缺失项是否明确。
- 是否先判断主要信息载体，再解释模块分工。
- 是否区分成品模块、正文变量和说服节点。
- 图片序列是否分析信息任务、承接和证据上限，而非只写画面概述。
- 每条路线是否有五个核心字段、支持样本、反例、适用条件和证据限制。
- 是否将单样本路线降级，将正样本共性保留为观察或假设。
- 是否把图片可见信息、作者体验或互动数字误写成功效、因果或企业事实。
