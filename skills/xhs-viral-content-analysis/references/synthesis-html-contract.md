# 综合 HTML 报告契约

## 定位

`synthesis-report.html` 是面向内容团队、管理者或外部合作方直接阅读的正式分析报告。页面要一眼看懂，同时保留报告、样本和截图证据的回溯能力。

报告只呈现研究范围、结论、差异、证据和适用边界。不得出现内部沟通语言、解释制作意图的元话语、制作说明、修改记录、版本、Gate、Skill、脚本、校验过程或本机路径。

## 实现起点

复制 `assets/XHS-Cross-Report-Synthesis-Template.html`，替换全部 `{{...}}` 占位内容。不得从图文或视频单批模板拼接出另一套综合主题。

根节点使用：

```html
<body data-report-template="xhs-cross-report-synthesis">
```

## 必需结构

- `data-report-part="navigation"`：主要章节导航。
- `data-report-part="synthesis-hero"`：标题、报告范围和核心结论。
- `data-report-part="synthesis-meta"`：报告数、样本数、研究对象、媒体与来源构成。
- `data-report-part="executive-summary"`：可见标题使用“核心结论”。
- `data-report-part="report-gallery"`：来源报告横向滑动快照。
- `data-report-part="lightbox"`：截图放大容器。

必需章节使用：

- `data-section="scope"`：研究范围和来源报告。
- `data-section="applicability"`：直接支持、迁移候选、平台假设和效果因果边界。
- `data-section="mechanisms"`：跨报告共性机制和代表证据。
- `data-section="routes"`：开放路线族、来源映射和代表证据。
- `data-section="media"`：图文与视频分工；输入只有一种媒体时如实说明，不硬造比较。
- `data-section="subjects"`：不同产品或研究对象在本批内容中的差异；对象不足 2 个时可以省略可见内容，但保留空状态说明。
- `data-section="diagnosis"`：由共性机制压缩出的内容诊断。

## 文案口径

- 用“面向转化目标”“内容说服力”“候选机制”等表达区分创作目标与已验证结果。
- 没有曝光、留存、投放、账号基线、负样本和统一转化数据时，不使用“高转化公式”“爆款公式”“必然提升”“导致成交”等结果性表述。
- “反复出现”必须有至少 2 份报告支持；单报告或单样本结论直接标明。
- 产品或研究对象差异只描述本批内容中的突出位置，不写成固定定位。
- 截图图注直接说明它支持什么判断，不写分析者的思考过程或自我辩护。
- 页面不向读者解释“为什么这样排版”“这个板块的作用是什么”或“为了避免误解”。标题和正文应直接表达有用内容。

## 证据呈现

每条核心机制和路线使用“结论 → 来源映射 → 代表截图 → 可复制点或适用条件”的顺序。来源映射证明跨报告重复，截图辅助快速理解。不得为了视觉完整而使用不相关证据。

主要证据图必须支持点击放大。正式交付中的图片使用 `data:` URI 内嵌，不依赖本机目录、网络图片、外部 CSS、脚本或字体。

## 横向宽度与响应式

- 页面主容器使用流动宽度与最大宽度组合，例如 `width: min(100% - 32px, 1280px)`。
- 所有标题、章节说明和内容容器设置 `min-width: 0`。长词、英文标识和样本 ID 使用 `overflow-wrap: anywhere`。
- `.section-heading`、其标题和说明默认使用可用横向宽度，不固定在狭窄列中；需要控制阅读长度时使用 `max-width: 72ch`，并确保窄屏自动回落为 `width: 100%`。
- 公式可以在宽屏保持单行，但必须设置可回落断行规则；不得以 `white-space: nowrap` 造成页面整体溢出。
- 报告快照使用横向滚动或按钮控制，不纵向堆叠全部报告。
- 多列机制、路线、媒体、对象和诊断区在手机端明确改为单列。
- 只有报告快照、时间轴或图片带可以在自己的容器中横向滚动；正文页面不得整体横向滚动。

## 禁止出现

- 内部版本、阶段状态、Gate、开发计划和修改过程。
- 制作说明、解释说明、阅读说明、Agent 或模型说明。
- `SKILL.md`、脚本命令、Schema、校验器和文件结构。
- 本机绝对路径、临时目录、账号凭证和服务商配置。
- 未经证据支持的高转化、爆款、销售或平台算法因果。
- 尚未替换的 `{{...}}` 模板占位符。

## 校验

```bash
python3 scripts/validate_synthesis_html.py output/synthesis-report.html
```

机械校验之外，还要在至少 `1440×900` 桌面端和 `390×844` 手机端检查：正文无整体横向溢出，标题和说明不形成不合理窄列，文字不遮挡，横向报告快照可操作，截图放大有效。
