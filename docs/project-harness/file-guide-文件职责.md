# 文件职责

| 文件 | 应保存 | 不应保存 |
| --- | --- | --- |
| `AGENTS.md` | 稳定入口、规则、边界、验证要求 | 每日进度、长历史、完整方法论 |
| `PROJECT_STATE.md` | 当前目标、状态、下一步、阻塞项 | 完整任务流水和过期背景 |
| `RUNBOOK.md` | 已跑通的重复流程、阶段契约 | 一次性尝试和未经验证的想法 |
| `DECISIONS.md` | 已接受的决策和原因 | 仍未确定的问题 |
| `DISCUSSION_QUEUE.md` | 需要人判断的开放问题 | Agent 可以自行验证的事项 |
| `REFERENCES.md` | 重要链接、资料和研究入口 | 大段复制外部正文 |
| `LESSONS_LEARNED.md` | 重复错误和改进经验 | 普通工作日志 |
| `task-states/*.md` | 真正活跃任务的独立状态 | 空任务、完成历史全集 |

判断标准：如果删除某段内容不会增加下一轮恢复上下文、误操作或返工成本，它通常不属于 Harness。
