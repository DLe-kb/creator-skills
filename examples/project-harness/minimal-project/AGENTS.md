# Example Project Guidance

## Purpose

This project demonstrates the minimum useful Project Harness.

## Continue work

Read `PROJECT_STATE.md` before changing files. Inspect only files related to the current task.

## Safety

Ask before deleting, overwriting, moving, publishing, changing permissions, or writing to external systems.

## Done means

- Explain what changed.
- Run the relevant validation.
- Update `PROJECT_STATE.md` only when the project goal, state, next step, or blocker changed.
